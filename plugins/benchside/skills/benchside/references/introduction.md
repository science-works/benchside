# Introduce Benchside before setup

When a researcher first asks what Benchside is or supplies the repository to
explore using it, give this introduction. If they have already explicitly asked
to install or proceed, show the explanation and continue; do not ask them to
approve the same setup again (omit the final question below). Do not repeat it on return, or treat development
work on this repository as a request to start a research notebook.

> Benchside adds scientific research roles and a private project notebook to your AI assistant. It helps you think through research questions, troubleshoot workflow problems and return to previous decisions. You choose where your records are stored. You can separately opt in to sharing reviewed workflow problems and workarounds with Science Works, a nonprofit research and policy studio. Our aim is to help researchers find and share useful software, solutions and workarounds, and understand where better support is needed.
>
> Would you like me to set it up and run through a few onboarding questions?

The community sentence states an aim, not a claim that community lookup exists.
Installation and optional sharing are separate choices. After agreement, follow
onboarding, discovering tools and doing supported setup steps for the researcher.
